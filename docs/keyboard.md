# Keyboard

Every action has a key. Three ways in:

| | |
|---|---|
| <kbd>⌘K</kbd> | **Command palette.** Type any action or place, then <kbd>↩</kbd>. <kbd>⌥↩</kbd> keeps a place as a background tab. |
| <kbd>?</kbd> | **Keyboard map.** A keyboard you can hover: a row lights its keys, a key lists its actions. |
| hold <kbd>⌥</kbd> | **Key badges.** Every button with a key shows it. |

Two habits cover the rest:

- **Areas.** <kbd>F6</kbd> walks sidebar, tabs, path bar, toolbar and listing. Inside an area the arrows move, <kbd>↩</kbd> acts and <kbd>Esc</kbd> returns to the listing.
- **Sequences.** <kbd>g</kbd> goes somewhere, <kbd>v</kbd> picks a view, <kbd>s</kbd> sorts. A pill shows what can follow.

Single letters work when no text box has focus. Chrome keeps <kbd>⌘T</kbd>, <kbd>⌘W</kbd> and <kbd>⌘L</kbd>.

This file is generated from `src/keymap.ts`, the same list the app reads.
