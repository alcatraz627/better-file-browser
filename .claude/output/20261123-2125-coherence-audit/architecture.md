# Architecture coherence audit (bfb, 2026-11-23)

Reviewer seat s-20261123-212504-fba3. Read-only: no file in the tree was changed except this one. Scratch scripts used for the import graph live in the session scratchpad, not the repo. No build, test or browser was run.

## Verdict

The code itself is more coherent than its paperwork. Every one of the 150 `src` modules is reachable from a bundle entry, there is exactly one value-import cycle, the low layers (`utils`, `kv`, `storage`, `layer`, `controls`, `nav`, `errors`) import nothing upward, and version numbers agree everywhere. The incoherence is at the edges that grew fast: the service worker still trusts callers as if only `file://` pages could reach it, although a content script now runs on every http(s) page; the README makes a privacy claim the code no longer honours; the checks the docs lean on (source ratchet, census, 157 browser walks, bundle freshness) have no runner, so they decay silently; and the same job (stored keys for web-page tools, relative-time text, home-folder detection, Prefs) is done in several places. Four findings are high, six medium, the rest low.
